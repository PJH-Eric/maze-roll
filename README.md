# 迷宮滾球（maze-roll）

3D 木質迷宮滾球。推著小球在迷宮裡跑，四種玩法：**同圖競速**、**搶星星**、**地板崩塌**、**逃出模式**。
單機（闖關／自由練習／對 1～7 位電腦）與線上最多 4 人對戰（另可 20 人觀戰、邀請連結、聊天室）。平板觸控優先，手機、桌機都能玩。

## 本機啟動

```bash
npm ci
npm start          # http://localhost:3090（Windows 可直接按 啟動遊戲.bat）
```

`node server.js` 同時提供靜態檔、`/health` 與 WebSocket（`/ws`）。本機開啟時前端自動連同源伺服器，不需要設定 `GAME_SERVER_URL`。

啟動視窗會列出本機與各網路介面的「同網路網址」。手機／平板連上相同 Wi-Fi 後，輸入對應 Wi-Fi 或乙太網路的網址即可開啟遊戲。

## 測試

```bash
npm test           # 規則單元測試（30 項）＋房間／邀請／觀戰／關房測試（24 項）
npm run verify     # 再加上真 WebSocket 的端對端檢查
```

另有需要瀏覽器的巡檢腳本（需要 Playwright）：`scripts/e2e-online.js`（線上全流程）、`scripts/audit.js`（全畫面 RWD 巡檢與截圖）、`scripts/shots.js`（單一畫面截圖）。

## 玩法規則摘要

- **同圖競速**：同 seed 迷宮，先滾進終點洞的人贏；多人局第一名抵達後完整倒數 10 秒，全員抵達也不提前結算；單人抵達立即結算。
- **搶星星**：90 秒；碰到星星 +1，被撿走就消失、不再補生，星星被搶光即提前結束；同分比較早拿到最後一顆者名次前。
- **地板崩塌**：腳下地磚開局 1.2 秒後開始碎裂（碎裂延遲依難度 3.2～1.2 秒）；掉下去淘汰；60 秒後場地隨機猝死；最後存活者贏。
- **逃出模式**：完美迷宮（無環）上沿唯一的路放 2～5 道彩色的門（依難度）。**鑰匙門**：同色鑰匙在該門之前的支線盡頭，帶著鑰匙走到門前永久開門；**踏板門**：踩同色踏板開門，只維持一段時間（依距離與難度計算，並進位到 5 秒的倍數，快關時門會閃爍），關上後可再踩。每位玩家的鑰匙與門狀態各自獨立；第一個抵達終點後倒數 10 秒，未逃出者為未完成，單人逃出立即結算；未逃出者依通過的門數、再依剩餘距離排名。**傳送門**：路旁 1～2 格的小岔路上有成對的發光光圈（依難度 1～3 對），走進一端從另一端出來，是自願走的捷徑；兩端一定在同一段（不會繞過任何一道門），也不會放在通往鑰匙／踏板的路上，所以關卡一定有解。可在闖關、自由練習、對電腦、線上對戰選擇。
- **每日挑戰**：首頁入口，可選同圖競速或逃出模式；以本機日期、玩法與難度固定種子，同一天同玩法同難度所有人都是同一張圖，兩種玩法各有五種難度；最佳時間與星星分玩法記錄，任一玩法完成都會累計連續挑戰天數（存本機 localStorage）。
- 球與球互相穿透、不碰撞（延遲再高也不卡手）。
- 難度五段：幼幼班／簡單／普通／困難／神話（迷宮大小）；電腦也是五段。各電腦有個別速度節奏、轉彎習慣與等長路線偏好；會記住走錯的岔路，避免反覆繞路。神話會規劃連續搶星星、評估傳送門捷徑，所有等級遵守相同球體物理與門鎖規則。
- 困難／神話迷宮會重接支線，增加三向及四向路口，保留原本長主路；競速與逃出維持樹狀通路，增加岔路不會產生繞門捷徑。電腦會補償移動阻力、加快反應，並在等長路線中減少不必要的轉彎；速度仍受相同輸入與物理規則限制。
- 闖關：可選「同圖競速」或「逃出模式」，各有五種難度各 100 關（難度可直接選，關卡依序解鎖），依完成時間評 1～3 星（逃出的基準時間含繞路拿鑰匙與開門）；兩種玩法進度各自獨立，存在瀏覽器 localStorage。逃出關卡迷宮大小：幼幼班 6～8、簡單 8～11、普通 10～14、困難 13～18、神話 16～22。

## 部署（預設：GitHub Pages 前端 ＋ Render 後端）

1. **後端（Render）**：以 `render.yaml` 建立 Web Service（`region: singapore`，免費方案）。在 Render 服務設定環境變數 `GAME_ALLOWED_ORIGIN`＝前端網址（如 `https://<帳號>.github.io`）；健康檢查為 `/health`。
2. **前端（GitHub Pages）**：repo Settings → Pages 選 GitHub Actions；到 Settings → Secrets and variables → Actions → **Variables** 新增 `GAME_SERVER_URL`＝Render 後端 HTTPS 網址，以及 `GA4_MEASUREMENT_ID`＝GA4 Measurement ID（格式 `G-XXXXXXXXXX`）。推到 `main` 即部署（workflow 會先跑測試，再把兩個公開設定注入 `public/js/config.js`）。
3. GA4 只追蹤遊戲畫面瀏覽，並以無 query/hash 的虛擬路徑區分畫面，不送出暱稱、房間邀請 token 等玩家資料。未設定有效 Measurement ID 時不載入 Google tag。

> 免費層限制：Render 服務閒置會休眠，第一次連線要等幾十秒（遊戲會顯示「連線中」）；房間資料只存在記憶體，服務重啟就會清空——房間本來就是可清理的暫時狀態。Render 不能修改既有服務的 region，需要換節點時請建立新服務、再更新 `GAME_SERVER_URL`，確認 `/health` 與線上對局可用後才停用舊服務。

## 已知限制與假設

- 「裝置傾斜」操作需要真機的陀螺儀（iOS 會要求授權），自動化測試環境無法驗證，預設為虛擬搖桿。
- 線上房不含電腦對手（電腦只在單機模式）。
- 全部音樂與音效以 WebAudio 即時合成，無外部素材、無授權問題；若要換成正式素材，改 `public/js/audio.js` 即可。

## 多語系（繁體中文／English）
- 語言核心 `public/js/i18n.js` 與箭頭解密相同；網址 `?lang=en`、`localStorage('game-island-lang')`、預設繁中。右上角地球鈕可切換。
- 介面文字以 `T('繁中原文', {變數})` 取得；英文字典在 `public/js/locales.js`（`window.MR_EN`，以繁中原文為鍵）。伺服器送來的系統訊息用 `M()` 依樣式比對翻譯。
- 新增文字時請同步補英文；`npm test` 內的 `tests/i18n.test.js` 會檢查缺漏與 `{變數}` 是否一致。
- 巡檢：`AUDIT_LANG=en node scripts/audit.js <寬> <高> <埠號>` 以英文介面巡檢，並檢查畫面是否殘留中文。

## 遊戲細節
- 球的直徑約為走道寬的 0.8 倍；滾動方向與轉角依真實滾動（頂端朝前進方向轉，轉角 = 位移 ÷ 半徑）。
- 時間一律顯示到小數點第二位（m:ss.cc）。第五個難度名稱為「神話」。
